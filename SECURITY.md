# Security policy

## Supported versions

Security fixes target the latest source release and the `main` branch. This experimental v0.x project does not promise fixes for older snapshots.

## Report privately

Please use [GitHub private vulnerability reporting](https://github.com/Idan707/chiki/security/advisories/new). Do not open a public issue for:

- exposed tokens, API keys, child data, transcripts, or recordings;
- authentication, webhook-signature, or rate-limit bypasses;
- unsafe remote-control or device behavior;
- dependency or build-chain compromise.

Include a concise impact statement, affected commit/version, reproduction steps, and a proposed mitigation if known. Remove real secrets and personal data from evidence.

You should receive an acknowledgment within seven days. Timelines for validation, fixes, and coordinated disclosure depend on severity and maintainer availability. Do not access data or systems you do not own, disrupt services, or retain personal data while researching.
